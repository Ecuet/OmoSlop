## Run your funny gifs on screen ;3

This app allows you to have any GIF or PNG you want on your screen as overlay <3\
Also it eats almost zero RAM (which is kinda expensive nowadays, so have fun)

## Compatibility

Currently tested only on Windows.\
I am unsure, if this app will work good on other OS.\
Probably no.

Also you need to have [FFmpeg](https://github.com/ffmpeg/ffmpeg) in the same folder with file.
